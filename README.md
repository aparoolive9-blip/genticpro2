An enterprise-grade Python tool designed for high-throughput ingestion, structural composition analysis, and pathogenic variant screening of cell-free DNA (cfDNA) and blood genomic extraction profiles. Robust Sequence Ingestion: Sanitizes and validates raw FASTA/FASTQ string inputs, normalizes nucleotides to uppercase, filters whitespace, and flags non-standard characters.

Structural Composition Analytics: Computes total length, base distribution (A, T, C, G, N), and Guanine-Cytosine (GC) content percentages.

Pathogenic Marker Screening: Screens sequences against reference gene markers (e.g., HBB, TP53) to identify potential Single Nucleotide Polymorphisms (SNPs) and structural alterations.

Executive Clinical Reporting: Automatically synthesizes analysis metrics and variant findings into an executive-ready clinical intelligence report format.
